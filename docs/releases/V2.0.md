# DaoEval V2.0

日期：2026-11-03。追蹤：[GitLab issue #1](https://gitlab.sjfood.us/osc-ai/daoeval/-/issues/1)。

V1.0 固定在原 GitLab main 提交 `3a17569d71879592e9e35a7c1897aa6aa3244be3`；V2.0 包含本輪平台迭代，不包含本機測試資料庫、憑證、真實執行結果及暫存產物。

## 使用者可見變更

- 建立實驗改為選題目、選測試對象、確認設定；自動帶入評分規則、產生名稱並預覽調用量。
- Agent 版本新增可編輯名稱，與接口模型 ID 分開展示。
- 多模型／版本分組比較，模型模式核對同一 Agent、模型路由不同及其他本地配置一致。
- 報告上半部精簡、執行與 AI 品質分開；評估歷史和技術異常收進詳情。
- 右側明細窗口、同題多模型回答並排、改善／退步篩選；JSON、HTML、PDF 匯出包含比較資料。
- 回答時間用秒顯示，成功回答平均／P95 與失敗等待、超時分開。
- 不完整規則判定不再顯示為整批 0%；無法判定不視為 Agent 回答失敗。
- AI 評估輸出精簡、截斷與格式分類重試、只補評失敗項、歷史及來源保留。
- 「設定」更名為「操作審計」；登入七天並自動續期，在同一資料目錄與加密金鑰下重啟後保留。

## 結果沿用

`src/server/compose-run.ts` 提供內部彙整函式，僅接受相同測試集、評分版本與重複次數的完整來源批次，保留原始結果及請求參照。彙整不調用模型，也不承接舊 AI 評分；回答使用新批次統一評估。此輪四模型彙整由本地協調流程執行，尚未提供一般使用者的跨實驗匯入表單。

## 升級與驗證

- Node.js 22；執行 `pnpm install --frozen-lockfile`、`pnpm run build:web`、`pnpm start`。
- 啟動時自動補齊版本名稱、評估來源欄位及雜湊會話表；歷史 Agent／實驗快照不改寫。升級前應備份資料庫與原有加密金鑰。
- 舊版記憶體登入會話無法遷移，第一次升級需重新登入。
- 發版檢查包含型別、構建、冒煙、登入、健康檢查、評估模型、AI 回答評估與容錯、判定、報告、版本名稱及模型彙整隔離測試。
- 瀏覽器已驗證多組建立、報告、右側並排、篩選及行動版；隔離測試不代表正式模型品質已通過。
- 遠端可變的 Prompt／Skill／知識庫仍需自行固定；本輪未重新完成 Docker 鏡像構建驗證。
