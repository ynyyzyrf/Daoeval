## 6. 佈局

- 僅桌面：最小 1280×720，設計基準 1440×900；不做行動端。
- 左側導航固定 220px（可收合至 56px 圖示列）；內容區最大 1280px，頁面邊距 `--sp-6`。
- 詳情頁頂部：麵包屑（`--fs-sm`、`--text-3`）→ 標題 + 狀態徽章 + 主要動作（右對齊）→ 內容區。
- 表格：表頭 `--bg-2`、`--fs-sm`、`--text-2`；列高 48px；首列固定對齊左，數字與時長右對齊。
- 抽屜寬 480px，從右滑入，遮罩 `#1b1f2466`。

## 7. 載入與回饋

| 狀態 | 規則 |
| --- | --- |
| 骨架屏 | 區塊形狀貼合實際內容（表格畫列、卡片畫塊），`--bg-2` 底 + 1.2s 呼吸；超過 400ms 才出現 |
| 進度 | 跑批用線性進度條（高 6px、底 `--bg-3`、填充 `--accent-500`）＋百分比＋已完成/總數；同時顯示失敗與攔截計數 |
| 空狀態 | 圖示（`--text-4`）＋一句說明（`--fs-sm`）＋一個主要動作；不使用插畫 |
| 錯誤 | 欄位級錯誤行內（`--err`、`--fs-sm`、欄位下方 `--sp-1`）；請求級錯誤右上 toast，8 秒自動關、可手動關 |
| 成功 | 右上 toast，2.5 秒自動關；不彈對話框 |
| N/A | 一律 `--text-3` 文字 "N/A"＋同列小字原因，不用 `-`、不用 0、不上紅色 |

## 8. 寫入方式

- 全部 token 放 `web/src/tokens.css`；`styles.css` 與組件只引用變數。
- 禁止在組件內硬寫色值、字級、間距、圓角；驗收時 `grep -E "#[0-9a-fA-F]{3,8}" web/src/components/*.tsx` 應無結果（tokens.css 除外）。
- 新控件先在本規範補一列狀態表，再實作。
