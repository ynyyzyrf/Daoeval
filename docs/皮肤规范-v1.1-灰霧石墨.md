## 0. 這套皮膚的意圖

低調奢華不是深色加金色。這套靠四件事撐：

1. **材質感來自紙與墨**：底色是極淡的冷霧灰，紙面純白，文字近墨黑。不用陰影做層次，用細線。
2. **層次靠線不靠框**：能用 1px hairline 分隔就不要卡片框；能靠留白就不要背景色塊。
3. **字重對比**：標題一輕一重（300 與 600 並置），標籤字距拉開，正文老實 400。這是「高級」的主要來源。
4. **數字是主角**：所有指標、耗時、樣本量用襯線字（Georgia）搭配 tabular-nums，像財報而不是後台。

反面清單（出現就不算過）：彩色主色按鈕、卡片陰影、圓角 10px 以上、斑馬紋表格、彩色圖表、漸層、發光、圖標滿天飛。

### 1.4 語義（全部去飽和）
| Token | 主色 | 淡底 | 用途 |

語義色只上文字與 1px 邊框／極淡底，不做大面積填充，不用純紅純綠。N/A 一律 `--dim`，不上任何語義色。

## 2. 字體與字階

- 介面：`"Microsoft YaHei UI", "PingFang SC", "Segoe UI", sans-serif`
- 數字（指標、耗時、樣本量、sha）：`ui-serif, Georgia, "Times New Roman", serif` ＋ `font-variant-numeric: tabular-nums`
- 等寬（路徑、JSON、日誌）：`ui-monospace, "Cascadia Mono", Consolas, monospace`

| Token | 字號／行高 | 字重 | 字距 | 用途 |
| --- | --- | --- | --- | --- |
| `--fs-display` | 26 / 36 | 300（可混 600） | 1.2px | 頁面主標題、詳情頁名稱 |
| `--fs-h1` | 18 / 26 | 600 | .6px | 卡片標題、區塊大標 |
| `--fs-h2` | 15 / 23 | 600 | .4px | 次級標題 |
| `--fs-body` | 14 / 22 | 400 | .2px | 正文、表格 |
| `--fs-sm` | 12.5 / 20 | 400 | .3px | 說明、摘要 |
| `--fs-label` | 10.5 / 18 | 500 | 1.5–1.8px | 表頭、統計標籤（拉開字距是小標籤的關鍵） |
| `--fs-num` | 30 / 40 | 400 | .6px | 統計數字（襯線） |
| `--fs-mono` | 12 / 20 | 400 | 0 | 代碼、路徑 |

標題的「輕重並置」是這套皮膚的簽名：主標題用 300 寫前半句、600 寫主體，例如 `首輪對照 ` + **`Oumi 形態 vs 純問答`**。每個頁面只用一次。

## 3. 間距

4px 基準。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--sp-1` | 4 | 圖示與文字 |
| `--sp-2` | 8 | 標籤內距、緊湊間隔 |
| `--sp-3` | 12 | 表單欄位、行內間隔 |
| `--sp-4` | 16 | 卡片內距 |
| `--sp-5` | 22 | 區塊內元素 |
| `--sp-6` | 34 | 區塊之間 |
| `--sp-7` | 44 | 頁面左右邊距 |
| `--sp-8` | 56 | 大段留白、空狀態 |

留白寧多勿少。區塊之間 34px 起，不要為了塞內容壓到 16px。

## 4. 圓角與陰影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--r` | `4px` | 按鈕、輸入框、卡片 |
| `--r-xs` | `2px` | 標籤、徽章 |
| `--shadow-drawer` | `0 10px 30px #14171A1F` | 抽屜、對話框（全站唯一允許的陰影） |

卡片、表格、統計帶一律不用陰影。圓角不准超過 4px（抽屜與對話框可用 6px）。

## 6. 佈局

- 最小 1280×720；設計基準 1440×900；不做行動端。
- 側欄固定 236px，底色 `--side`，右側 1px `--line`。品牌區字距 2.6px，下方 30px 空白。
- 內容區左右邊距 44px，內容最大寬 1280px。
- 詳情頁：麵包屑（12px、`--dim`）→ 標題（26px 300 混 600）＋副行（12.5px `--muted`）→ 右側動作（次按鈕＋主按鈕）→ 內容。
- **統計帶不用卡片框**：四欄，頂部 1px `--ink`（重線）、底部 1px `--line`，欄間 1px `--line-soft`，首欄不帶左線且左對齊到內容邊。數字 30px 襯線。
- 表格：無外框、無斑馬紋；表頭 `--fs-label`、`--dim`、下方 1px `--line-soft`；列線 1px `--line-soft`；行高 48px；數值欄右對齊、tabular-nums；首欄左對齊到內容邊、最後一欄右對齊到內容邊。
- 區塊標題：13px 600、字距 1.6px，下方 1px `--line`，右側可放一行說明（11.5px `--dim`）。
- 抽屜寬 480px、`--r` 6px、右側滑入、遮罩 `#14171A66`。

## 7. 圖表（若後續加）

只用墨階（`--ink` / `--ink-2` / `--muted` / `--dim`）與一條 `--acc` 線，不用彩色系列；柱寬 ≤ 12px、間距 ≥ 8px；網格線 1px `--line-soft`，不要虛線；標註數字用襯線。

## 8. 載入與回饋

| 狀態 | 規則 |
| --- | --- |
| 骨架 | 貼合實際形狀（表格畫列、卡畫塊），底 `--line-soft`、1.2s 呼吸；>400ms 才出現 |
| 進度 | 高 4px 線性條，底 `--line-soft`、填充 `--acc`；同時顯示百分比與已完成/總數 |
| 空狀態 | 一行標題（15px 600）＋一句說明（12.5px `--muted`）＋一個主按鈕；不用插畫，可用 1px 線框圖示 |
| 錯誤 | 欄位下 `--bad`、12px；請求錯誤右上 toast、白底、1px `--line-strong`、左側 2px `--bad`，8 秒關 |
| 成功 | 右上 toast、左側 2px `--good`、2.5 秒關 |
| N/A | `--dim` 文字＋同列小字原因，不上色、不用「-」、不用 0 |

## 9. 驗收（換膚完成要能過）

1. `grep -E "#[0-9a-fA-F]{3,8}" web/src/components/*.tsx web/src/*.tsx` 在組件內 0 命中（`tokens.css` 與 mock 除外）。
2. 頁面上沒有任何卡片陰影；圓角一律 ≤ 4px（抽屜／對話框 ≤ 6px）。
3. 統計區是「細線分隔帶」而不是四個卡片框。
4. 所有指標數字為襯線體且 tabular-nums，小數位一致（百分比 1 位）。
5. 主按鈕是墨色（`#232C35`），全站沒有彩色主按鈕。
6. 表格無斑馬紋、無外框，只有列線與表頭線。
7. 標籤字距拉開（≥1.5px），與正文可明顯區分。
8. **導出 HTML／PDF 使用同一份 token**，導出件與頁面看起來是同一套皮膚（這條最容易漏）。
9. 對照 `skin-c-refined.png` 截同一頁（報告頁），兩張放一起看不出是兩套設計。
