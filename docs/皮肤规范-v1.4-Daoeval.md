# Daoeval 皮膚規範 v1.4「Linear 淺色 · 密度版」

取代 v1.3；v1.3 保留作歷史參考

## 顏色

- 畫布 `--canvas #F4F4F6`；面板 `--panel`；分隔線 `--line`。
- 警告使用 `--warn-bg #FFF8E6`、`--warn-line #F2D69A`、`--warn-ink #6B5300`；文字對 `warn-bg` 對比度為 6.92:1。
- 元件與 CSS 不直接寫色值，僅引用 token。

## 字階與字重

| 角色 | 字級／行高 | 字重 |
| --- | --- | --- |
| h1 | 22 / 28 | 600 |
| card | 15 / 20 | 600 |
| body | 13 / 19 | 400 |
| cap | 12 / 17 | 400 |
| pill | 11 / 16 | 400 |
| mono | 11.5 / 19 | 400 |

標題使用 `--fw-title` 600；正文使用 400。表格數字使用等寬字與 tabular figures，靠右對齊。

## 間距與密度

- 間距階梯僅用 4 / 8 / 12 / 16 / 24 / 32；禁用 20。
- 資料列高度 `--row-y: 34px`。
- 說明欄寬 280px，允許換行，不以縮小文字換取密度。

## 卡片與外殼

- 卡片為白底、1px `--line`、10px 圓角與 `--sh-card` 淺投影，內距 `--card-pad: 16px`。
- 側欄 200px；選中項是 2px 靛藍左線，透明底；圖標 16px、文字 13px；超長名稱省略並提供 tooltip。
- 頂欄的搜尋、更多、分享置於淺邊框按鈕分組；主按鈕獨立。

## 警告塊

歷史批次與驗證失敗使用 `Notice` 警告態：`warn-bg` / `warn-line` / `warn-ink`、8px × 12px 內距與控制項圓角。資訊態也必須經由 `Notice` 元件，不另寫色值。

## 資料呈現／狀態

- 統計匯總（例如分支的成功／失敗／攔截計數、頂部批次狀態摘要）允許使用 pill 底色；單條記錄的狀態一律「圓點＋單詞」，不得使用 pill。

## 驗收

1. `grep -E "#[0-9a-fA-F]{3,8}" web/src/**/*.tsx` 為 0 命中。
2. 全站不使用 20px 間距。
3. 1440px 與 1280px 寬度皆保持可讀，首頁可在首屏顯示更多列表內容。
