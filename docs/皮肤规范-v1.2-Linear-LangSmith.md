# Agent 評測平台 皮膚規範 v1.2「Linear × LangSmith」

狀態：已定（用戶指定 Linear + LangSmith 類型精緻開發者工具風格） | 撰寫：Vera（產品） | 日期：2026-10-30
取代：皮肤规范 v1.1「灰霧石墨」、视觉规范 v1.0（色票全部作廢）。
參考稿：`docs/skin-linear.png`（1440×900，報告頁：試行明細）

## 0. 這套的方向

不是行銷頁的高級感，是**開發者工具的精密感**。四個來源：

1. **深色、低對比、hairline**：黑底不用純黑，靠 #08090A / #0F1011 / #131415 三層與 1px 線分層，不用大陰影。
2. **資料是主角，用等寬字**：ID、耗時、分數、錯誤分類、Trace 全部 `mono` + `tabular-nums`；正文才用無襯線。
3. **主色極度克制**：#5E6AD2 只出現在選中列左線、主按鈕、focus、搜尋快捷鍵。全站沒有第二個彩色裝飾。
4. **三欄工作區**：左導航 220、中間列表 + 篩選、右側 400 明細面板。看一條試行的所有證據不用跳頁。

反面清單（出現就不算過）：大圓角卡片牆、大陰影、漸層、彩色圖標、超過兩個彩色同時出現、按鈕放大到 40px 以上。

## 2. 字體與字階

- 介面：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`
- 等寬（ID、時間、耗時、分數、JSON、Trace、錯誤分類）：`'SF Mono', 'JetBrains Mono', Consolas, 'Cascadia Mono', monospace`
- 全部數字 `font-variant-numeric: tabular-nums`。

| Token | 字號／行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `--fs-title` | 17 / 24 | 600 | 頁面／詳情標題（配狀態膠囊） |
| `--fs-h` | 13 / 18 | 600 | 面板標題、區塊標題 |
| `--fs-body` | 13 / 20 | 400 | 正文、表格、按鈕、導航 |
| `--fs-sm` | 12 / 18 | 400 | 說明、meta、膠囊 |
| `--fs-xs` | 11 / 16 | 500 | 表頭、小標籤、kbd |
| `--fs-mono` | 11.5 / 20 | 400 | 所有資料欄位 |
| `--fs-num` | 16 / 22 | 500 | 指標數字（等寬） |

規範：正文字號一律 13；只有標題 17、表頭 11、資料 11.5 三種偏離。禁用 14、15 這種半檔。

## 3. 間距

4px 基準：`--sp-1 4` / `--sp-2 8` / `--sp-3 12` / `--sp-4 16` / `--sp-5 20` / `--sp-6 24`。
表格單元格橫向 12px、行高 34px；面板內距 14px；頁面左右 20px。密度優先，不要為留白犧牲一屏能看的行數。

## 6. 佈局

- 最小 1280×720；設計基準 1440×900；不做行動端。
- 左導航 220px（`--panel` + 右側 1px `--line`）：頂部工作區名、分組標籤（11px `--dim`）、項目高 30px、底部使用者。
- 頂欄 44px：左麵包屑（12.5px），右側搜尋框（含 `⌘K`）、次按鈕、主按鈕。
- 工作區三欄：列表區（flex）＋ 明細面板 400px（`--panel`、左側 1px `--line`）。
- 標題列：17px 標題 ＋ 狀態膠囊；下一行 meta（12px `--dim`，項目以 `·` 分隔）。
- 指標帶：**不是卡片**，是一個 1px 邊框容器，內含 6 格等寬區塊、欄間 1px 線；標籤 11px，數值 16px 等寬。
- 篩選列：chip 一排 ＋ 右側檢視選項（分支、N）。
- 表格：表頭吸頂（`--panel` 底）、行高 34、列線 1px `--line-soft`、首欄最寬、數字右對齊等寬。
- 明細面板：標題列（面板名 + 等寬 ID）＋ 區塊堆疊，每區塊小標籤 11px ＋ 內容；內容用 `--bg` 底、1px `--line`、5px 圓角的等寬框。
- 底部狀態列 26px：左側計數、右側快捷鍵提示。

## 7. 資料呈現規則

- 時間 `2026-10-30 16:20`；耗時 `142 ms`；分數 `1.00` / `0.00` 固定兩位；百分比一位小數。
- 錯誤分類顯示中文（只讀攔截／逾時／認證失敗／映射失敗／連線失敗／限流），原始枚舉碼放 `title` 屬性。
- N/A 一律 `--dim`，不寫 0、不寫 `-`；旁邊以小字標原因（測試集未覆蓋／Agent 未提供證據／只讀未測／樣本不足／尚未執行）。
- Trace 時間欄固定寬 42px 右對齊等寬；關鍵行用 `--ink` 加粗，其餘 `--muted`。
- 狀態優先順序：failed > blocked > n/a > passed（同一案例多分支並列時，失敗排前）。

## 8. 載入與回饋

| 狀態 | 規則 |
| --- | --- |
| 骨架 | 表格畫列（34px 高、`--line-soft` 底）、面板畫區塊；>300ms 才出現 |
| 進度 | 高 2px 線性條、底 `--line`、填充 `--acc`；旁附 `3/18` 等寬計數 |
| 空狀態 | 一句 13px 標題 ＋ 一句 12px `--dim` 說明 ＋ 一個主按鈕；左對齊、不用插畫 |
| 錯誤 | 面板內 `--err` 12px 行內提示；請求錯誤用右下 toast（`--elev`、1px `--line`、`--r`）、5 秒關 |
| 成功 | 右下 toast、綠點前綴、2 秒關 |
| 鍵盤 | `⌘K` 指令面板、`⌘↵` 執行、`ESC` 取消／關閉；所有可點元素 `:focus-visible` 有 2px `--acc` 外環 |

## 9. 驗收

1. `grep -E "#[0-9a-fA-F]{3,8}" web/src/components/*.tsx web/src/*.tsx` 在組件內 0 命中（`tokens.css` 除外）。
2. 全站只有一個彩色主色 `#5E6AD2`，且只出現在指定三處；沒有其他彩色裝飾或漸層。
3. 主要資料（ID、耗時、分數、時間、錯誤分類、Trace）全部等寬字且 `tabular-nums`。
4. 表格行高 34、表頭吸頂、選中列有左側 2px `--acc`。
5. 報告頁為「列表＋明細」三欄，點任一行右側明細同步更新，不跳頁。
6. 狀態只用 6px 點與 19px 膠囊，無整行底色。
7. 沒有卡片陰影；全站唯一陰影是浮層。
8. 快捷鍵 `⌘K`、`⌘↵`、`ESC` 可用，且 focus 環可見。
9. 導出 HTML／PDF 與頁面同一套 token（深色），數值一致。
