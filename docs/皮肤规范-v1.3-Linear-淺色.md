## 0. 方向

Linear 的淺色語言：**白卡片浮在極淺灰畫布上、近乎無邊框（靠 1px 環形陰影）、主色幾乎不出現、類型小而準**。整個介面看完只剩灰階，彩色只出現在狀態點與兩個地方。

四條規矩：

1. **卡片靠環形陰影，不靠描邊**：`box-shadow: 0 1px 2px rgba(16,18,20,.05), 0 0 0 1px rgba(16,18,20,.05)`，圓角 9px。禁止 2px 以上邊框。
2. **主色 #5E6AD2 只出現在三處**：選中列左側 2px、focus 外環、文字連結。不做彩色按鈕、不做彩色標頭。
3. **小而準的字**：正文 12.5、標題 14、資料 11.5 等寬、表頭 11.5。不用 16 以上，除非指標數字。
4. **密度靠 12px 間距與 38px 行高**，不靠大留白。

反面清單：深色底、漸層、大陰影、彩色按鈕、圓角超過 12、圖標超過 1.8 線寬、滿屏 pill。

## 2. 字體與字階

- 介面：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`

- 數字一律 `font-variant-numeric: tabular-nums`。

## 3. 間距與尺寸

4px 基準：`4 / 8 / 12 / 16 / 20 / 24`。
- 側欄 244px；頂欄 48px；工作區內距 12px、卡片間距 12px；明細面板 396px。
- 表格行高 38px、儲存格內距 12px；側欄項目 28px；按鈕高 26px。
- 例外：含副行的表格（例如案例表「名稱＋輸入摘要」）行高以內容為準，可到 56–60px，但同一欄內所有列必須等高，不可一行 38 一行 60。
- 卡片圓角 9px；控件 8px；pill 6px；頭像與狀態點 999px。

## 4. 陰影

| Token | 值 | 用途 |

| `--sh-card` | `0 1px 2px rgba(16,18,20,.05), 0 0 0 1px rgba(16,18,20,.05)` | 所有卡片（取代描邊） |

## 6. 佈局

- 最小 1280×720；基準 1440×900；不做行動端。
- 左側欄 244px（`--side`、右側 1px `--line`）：頂部產品名與標記（不放假的 workspace 切換、不放假頭像）；「＋ 新建實驗」按鈕（白底、描邊、帶 `⌘N`）；主導航七項皆為真實頁面：概覽／搜尋／Agent／測試集／實驗／報告／設定；「最近實驗」分組（**資料必須來自 API，空則整組隱藏**，圓點顏色用該實驗的真實狀態，不可按順序造色）；底部只放版本號，**不放使用者名稱（V1.0 沒有登入，顯示使用者即是假資料）**。
- 側欄硬性規則：不得出現任何硬編的項目、分組或人名；非導航內容一律有資料來源，且空資料時整塊消失而不是顯示佔位。
- 頂欄 48px（白底）：頁名 14px 600 ＋ 麵包屑 12px `--dim`、狀態 pill 按鈕、`＋ 篩選`；右側圖示鈕、分享、主按鈕。
- 工作區：畫布 `--canvas`、內距 12、兩欄（列表 flex ＋ 明細 396）、間距 12。
- 列表欄：小標題（13px 600 ＋ 11.5px `--dim` 說明）→ 白卡（內容表格）→ 底部狀態列（26px，白底、1px 上邊、左右 14）。
- 明細卡：標題列（13px 600 ＋ 等寬 ID）→ 內容區（12/14 內距、區塊間 13px）→ 每區塊小標籤 11px `--dim` ＋ 內容；內容框用 `--canvas` 底、6px 圓角、等寬 11.5。

## 7. 資料呈現

- 時間 `16:20:44`（同日）／`10-30 16:20`（跨日）；耗時 `142 ms`；分數 `1.00` 兩位；百分比一位小數。
- 錯誤分類顯示中文（只讀攔截／逾時／認證失敗／端點不存在／限流／服務端錯誤／請求被拒／回應解析失敗／映射失敗／連線失敗），原始枚舉碼放 `title`。唯一來源為 `src/shared/types.ts` 的 `ERROR_CLASS_LABELS`；本規範不再另外維護第二份清單。
- N/A 用 `--dim`，可點開原因；不寫 0、不寫 `-`。
- 每列狀態用「圓點＋單詞」，不用 pill；分類欄用純文字（`--muted`），也不加底色——同一欄混用 pill 與純文字會顯亂，整欄統一純文字。
- Trace 時間欄固定 44px 右對齊等寬，關鍵行 `--ink` 加粗。

## 8. 載入與回饋

| 狀態 | 規則 |
| --- | --- |
| 骨架 | 表格畫行（38px、`--line-2` 底）、卡片畫塊；>300ms 才出現 |
| 進度 | 高 2px 條、底 `--line`、填充 `--acc`；旁附 `3/18` 等寬 |
| 空狀態 | 一句 13px 標題 ＋ 一句 11.5px `--dim` ＋ 一個主按鈕；左對齊、不用插畫 |
| 錯誤 | 行內 `--red` 11.5px；請求錯誤右下 toast（白卡＋`--sh-pop`）、5 秒關 |
| 成功 | 右下 toast、綠點前綴、2 秒關 |
| 鍵盤 | `⌘K` 指令面板、`⌘N` 新建、`⌘↵` 執行、`ESC` 取消；`:focus-visible` 一律 2px `--acc` 外環 |

## 9. 驗收

1. 組件內 `grep -E "#[0-9a-fA-F]{3,8}"` 0 命中（`tokens.css` 除外）。
2. 介面為淺色：畫布 `#F7F7F8`、卡片純白、無深色區塊。
3. 卡片一律用 `--sh-card` 環形陰影，沒有 2px 以上描邊、沒有第三種陰影。
4. 主色只有一處 #5E6AD2，僅出現在選中列左線、focus、連結。
5. 資料欄位全部等寬且 tabular-nums；表格行高 38、表頭 11.5。
6. 狀態只有圓點與 pill 兩種形態，無整行底色。
7. 報告頁為「列表＋明細」兩欄，點行右側同步、不跳頁。
8. 快捷鍵 `⌘K`／`⌘N`／`⌘↵`／`ESC` 可用，focus 環可見。
9. 導出 HTML／PDF 同皮膚，數值一致。
